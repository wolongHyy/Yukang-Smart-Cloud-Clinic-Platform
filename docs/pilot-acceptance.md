## 2. 试点前门禁

- [ ] 诊所负责人、医生、药师和数据管理员已阅读并签署隐私与使用告知。
- [ ] 平台密钥、成员令牌不得共用；按实际岗位创建 RBAC 账号。
- [ ] Edge 设备已登记，设备令牌已安全保存，旧设备已吊销。
- [ ] 数据库备份可恢复，且恢复后能核实一条真实业务链。
- [ ] 更新包已验签，升级失败能够恢复旧版本并重新启动。
- [ ] 诊所明确 AI 输出仅作辅助，最终诊断和处方由医生确认。

## 5. 每日反馈

每天记录以下内容：

- 门诊量、处方量、收费金额、发药数量。
- 哪些字段/按钮不理解，首次使用需要多少分钟完成一次接诊。
- AI 建议是否被采纳、拒绝原因和医生判断。
- 任何数据不一致、重复、丢失、卡顿、崩溃或权限问题。
- 当天是否生成备份，备份是否可读。

## 6. 严重问题处理

出现以下任一情况，立即暂停试点并回滚：

- 患者明细出现在控制面、日志或非授权位置；
- 处方金额、库存或收费无法对账；
- 已保存病历被覆盖或丢失；
- 未授权用户可跨组织/跨门店访问数据；
- 升级后无法启动或健康检查失败且回滚失败；
- 医生无法确认 AI 建议却已进入正式处方。

## 7. Go / No-Go 规则

- [ ] 连续 14 个工作日无严重数据事故。
- [ ] 所有 P0/P1 问题关闭，P2 问题有明确负责人和日期。
- [ ] 至少两名真实临床用户完成独立操作验收。
- [ ] 真实业务抽样能回溯到原始记录、收费、药房和审计。
- [ ] 诊所负责人、实施负责人和研发负责人共同签字确认。
