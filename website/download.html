04 / DOWNLOAD FAQ

安装前后，最容易遇到的四个问题。

如果下载或安装失败，先保留错误截图、文件名和哈希结果，不要反复运行来源不明的修复工具。

Windows 提示“未知发布者”怎么办？

v5.1.0 的 Authenticode 状态是 NotSigned，因此浏览器和 Windows 无法验证发布者。先核对官网 SHA256；只有哈希完全一致时，才由你决定是否继续安装。正式商用版必须使用受信任的代码签名证书重新构建。

下载后的哈希不一致怎么办？

不要运行该文件。删除后重新从本官网或 GitHub Release 下载，再次计算哈希。如果仍不一致，先检查网络、代理和下载工具，不要通过关闭杀毒软件来强行运行。

为什么安装包不在 GitHub 源码目录里？

安装包约 247 MiB，不进入 Git 历史，避免仓库膨胀。源码放在 Git 仓库，可供下载的安装包放在 GitHub Release，并由官网的独立下载目录提供相同版本。

可以在多台电脑上写同一份数据吗？

不要直接复制或同时使用同一个 SQLite 数据库文件。需要多端访问时，应让手机或平板通过同一局域网访问运行在主机上的同一套程序；需要换机时使用系统内提供的备份与恢复流程。
